# Brand guidelines

## Brand idea

A compass offers direction without dictating one fixed route. AI Engineering Compass brings together timeless software craft and modern AI tools so engineers can make informed decisions.

## Voice

- Practical, clear, and welcoming.
- Curious rather than prescriptive.
- Explain the reason behind recommendations.
- State assumptions, trade-offs, and limits.
- Prefer specific examples over slogans.

## Colour palette

| Name | Hex | Use |
|---|---|---|
| Warm ivory | `#F3EEE5` | Main light background |
| Soft white | `#FFFDF8` | Cards and clear space |
| Sand beige | `#E7DCCB` | Secondary surfaces |
| Charcoal | `#272522` | Primary text and mark |
| Burnt amber | `#C56A32` | Directional accent and emphasis |
| Muted taupe | `#CBB99E` | Subtle dividers and details |

Use charcoal for readable text on light surfaces. Do not use amber for long body copy or small text on beige. For dark surfaces, use soft white text and the amber accent sparingly.

## Logo assets

The logo has two official forms:

- **Primary horizontal lockup:** [`ai-engineering-compass.svg`](../assets/brand/ai-engineering-compass.svg), for README pages, articles, presentations, and other wider spaces.
- **Standalone compass-A mark:** [`compass-mark.svg`](../assets/brand/compass-mark.svg), for avatars, compact placements, and square layouts.

The horizontal lockup combines the geometric A with a compass ring and the project wordmark. The standalone mark uses the same central A and compass details.

## Using the logo

The logo is shared so contributors and community members can identify and point others to the project. You may use either official asset in contributions, articles, tutorials, presentations, learning material, and community posts that reference AI Engineering Compass.

Please:

- Credit **AI Engineering Compass** and link to this repository or [the brand asset license](../LICENSE-BRAND).
- Use the SVG source where possible so the mark stays sharp at different sizes.
- Keep the mark's proportions; do not stretch, skew, rotate, or add effects.
- Preserve the core palette and ensure enough contrast against the background.
- Leave clear space around the mark.
- Use the standalone mark when the full wordmark would be too small to read.
- State when you have modified the artwork and retain the attribution required by CC BY 4.0.

Do not use the logo in a way that suggests the project endorses a product, article, service, or organisation, or that someone is an official maintainer when they are not. This is a usage guideline, not a restriction on ordinary attribution or contribution.

## Typography

Use a clean sans-serif for headings and body copy. Prefer a readable system font stack in web contexts. Avoid overly condensed or decorative faces.

## Design principles

Warm, calm, editorial, and direct. Use whitespace generously. Prefer simple geometry and clear information hierarchy over decorative technology motifs.
