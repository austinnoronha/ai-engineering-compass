## Use these standards with AI coding assistants

You can use the Compass as a practical engineering baseline in your own code repository. The [integration guide](../integrations/README.md) includes ready-to-copy templates for Claude Code, Cursor, and assistants that support `AGENTS.md`.

The integration pack explains canonical-reference and local-snapshot adoption, and provides an end-to-end SDLC skill covering discovery, planning, design, implementation, verification, review, release preparation, and operational learning.

When using canonical references, point assistants to the [Compass documentation index](https://github.com/austinnoronha/ai-engineering-compass/blob/main/docs/README.md) and ask them to open the topic guides relevant to the change. Do not assume an assistant has read a page merely because its URL appears in an instruction file.

Guides are living documents. Check each page's status, review date, scope, and references before applying its recommendations.
