# AI Engineering Compass brand assets

This folder contains the official, editable SVG artwork for the project.

| Asset | Best used for |
|---|---|
| [Primary horizontal logo](ai-engineering-compass.svg) | README headers, articles, presentations, and wide layouts |
| [Standalone compass-A mark](compass-mark.svg) | GitHub avatar, icons, compact layouts, and square placements |
